# AetherEngine v1.0.0 — Combat FX Rendering

- Added a Metal combat-FX pipeline for transient muzzle, tracer and impact events.
- Added camera-facing muzzle/impact billboards and camera-facing tracer strips.
- Added alpha fade based on engine event lifetime.
- Added non-depth-writing FX rendering so effects do not corrupt world depth.
- Added a focused combat-FX lifetime/index regression test.
- Existing engine/gameplay tests remain enabled.

This milestone renders the existing clean-room engine FX events on the iOS Metal view; it does not bundle Valve game assets.
