# AetherEngine v1.5.0

## NPC navigation integration

- Fixed navigation graph insertion so directed links can be added in arbitrary order.
- A* now traverses source-tagged links rather than relying on contiguous per-node storage.
- Added `AetherNPCNavigation` route building and waypoint steering.
- Added `AetherNPCController` to combine perception/state decisions with optional A* navigation.
- Navigation remains an optional enhancement; NPCs can retain direct steering when a route is unavailable.
- Extended navigation regression coverage to exercise arbitrary link insertion and controller integration.

This remains a clean-room implementation and contains no Valve/Steam game assets or proprietary source.
