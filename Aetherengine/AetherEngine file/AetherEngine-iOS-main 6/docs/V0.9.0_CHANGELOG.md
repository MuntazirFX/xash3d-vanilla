# AetherEngine v0.9.0 — In-game HUD

## Implemented

- Added `AetherHUDView.swift` as the runtime HUD overlay for the iOS game view.
- HUD reads health, armor, current weapon, clip ammo and reserve ammo directly from the C runtime bridge.
- Added centered four-segment crosshair.
- Added temporary pickup/gameplay message display.
- Added damage-screen feedback driven by the engine's damage flash value.
- HUD is placed above Metal rendering and below touch controls; it does not intercept input.
- Kept the existing engine data model and bridge APIs; no copyrighted game assets are bundled.

## Integration

`DashboardView` now composes the game screen as:

1. Metal world/model renderer
2. Aether HUD overlay
3. Existing touch controls
4. Close button

## Scope

This milestone makes the existing HUD runtime state visible on the iOS gameplay screen. It is not a claim of complete Valve HUD/VGUI compatibility.
