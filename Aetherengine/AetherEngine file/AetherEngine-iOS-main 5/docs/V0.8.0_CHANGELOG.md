# AetherEngine v0.8.0 — Combat FX Runtime

## Added
- Fixed-size combat FX event pool.
- Muzzle, tracer and impact FX events generated from gameplay combat events.
- FX lifetime/age/intensity tracking with automatic expiry.
- FX event accessors for the iOS/Metal presentation layer.
- Runtime integration so fire/hit/kill events produce presentation FX.
- Regression test covering emission, lifetime expiry and impact data.

## Scope
This milestone provides the runtime data path for visual effects. It does not bundle Valve game assets and does not claim full GoldSrc renderer parity yet.
