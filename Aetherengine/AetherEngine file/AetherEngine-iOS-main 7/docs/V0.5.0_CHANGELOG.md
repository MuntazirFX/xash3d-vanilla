# AetherEngine v0.5.0 — MDL Material Pipeline

## Implemented
- Correct GoldSrc studio vertex/normal storage stride (vec3 = 12 bytes).
- Preserve per-expanded-vertex source bone index.
- Decode studio triangle-command UV coordinates.
- Decode the first embedded MDL paletted texture to RGBA.
- Added C bridge accessors for MDL UVs, bone indices and texture pixels.
- Updated the iOS Metal MDL vertex layout to position/normal/UV.
- Updated the Metal MDL fragment path to sample an embedded model texture.
- Added regression coverage for the corrected MDL geometry path.

## Verification
Host CMake build completed with `-Wall -Wextra -Werror`.
CTest: 7/7 tests passed.

## Scope
This milestone improves real MDL asset rendering. Full skeletal animation, multiple
bodypart/material selection, texture animation and viewmodel placement remain later
milestones.
