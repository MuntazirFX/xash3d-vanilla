# AetherEngine v1.3.0 — NPC Combat Profiles

- Added data-driven NPC profiles for the current Half-Life/OpFor monster class names.
- Added hostile/friendly classification and melee/ranged attack archetypes.
- Added an NPC spawn factory for runtime integration.
- Added common NPC attack damage/cooldown dispatch.
- Extended monster runtime state with attack damage, wind-up and faction flags.
- Preserved the existing Headcrab attack path while routing other hostile NPCs through the common combat path.
- Added a v1.3.0 regression test.

No Valve game assets or proprietary source code are included.
