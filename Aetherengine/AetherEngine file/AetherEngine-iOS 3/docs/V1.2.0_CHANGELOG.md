# AetherEngine v1.2.0 — NPC AI Runtime

## Added
- Real AI state model: idle, alert, chase, attack and dead.
- Distance-based target acquisition and target loss hysteresis.
- Configurable sight, attack and lose-target ranges.
- Fixed think interval to keep AI deterministic and bounded per frame.
- Chase steering with last-seen target position.
- Attack cooldown tracking and attack counters.
- Runtime AI state storage for every monster slot.
- Headcrab attack gating now uses the AI controller as well as the monster attack cooldown.

## Validation
- Added `AetherAI_V120Test`.
- Existing regression tests remain registered.
