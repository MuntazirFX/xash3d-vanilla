# AetherEngine v0.4.0

## Implemented
- `engine/model/AetherMDLSequence.h/.c`
  - Parses MDL sequence descriptors safely.
  - Exposes sequence labels, FPS, frame counts, blend ranges and bounds.
- `engine/anim/AetherMDLAnimator.h/.c`
  - Sequence selection and playback timing.
  - Looping/non-looping playback.
  - Current frame and normalized frame queries.
- `engine/model/AetherMDLGeometry.c`
  - Correct 36-byte studio mesh descriptor stride.
  - Correct 16-byte studio vertex/normal stride.
  - Decodes triangle strip/fan command streams.
  - Adds bounds checks for malformed/truncated model data.
- Added two regression tests and CMake test registration.

## Verification
- Host C11 build: PASS.
- 7/7 CTest tests: PASS.

## Not claimed yet
